# Banking Microservices & AI Agent

An AI-powered banking application built using Spring Boot Microservices, Spring AI and Model Context Protocol (MCP).

## Project Overview

This project aims to develop a modern banking system based on a microservices architecture, enhanced with an AI agent capable of interacting with banking services.

## Project Architecture

### Part 1 – Microservices Architecture

- **Customer Service:** Customer management.
- **EBank Service:** Bank account management and banking operations.
- **OpenFeign:** Communication between microservices.
- **Resilience4J:** Fault tolerance and Circuit Breaker.
- **API Gateway:** Centralized access to microservices.
- **Discovery Service:** Service registration and discovery.
- **Swagger UI & Postman:** Backend API testing.

### Part 2 – AI Agent & MCP

- Develop an AI Agent using Spring AI.
- Expose microservices functionalities through MCP.
- Connect the AI Agent to banking microservices.
- Test using REST Client, Telegram and Discord.
